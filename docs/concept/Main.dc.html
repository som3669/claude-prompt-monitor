CLAUDE PROMPT MONITOR · VS CODE EXTENSION · CONCEPT

Know the moment Claude needs you — and the moment it is done.

A long prompt is something you walk away from. The monitor spends your attention only when it is worth it, and answers “what happened?” in one glance when you come back. Every surface — status bar, Monitor panel, notifications, desktop widget — shows the same state.

WHILE A PROMPT RUNS, IT IS IN ONE OF FOUR STATES
Needs you

Claude asked a question, has a plan to approve, or is showing a permission prompt. It cannot continue.

Amber everywhere · the question itself in the notification · the ETA clock pauses

Working

Generating, or running tools. Progress comes from past prompts and from Claude’s own task list.

Elapsed / ETA · the current step and how long it has run · 3/7 tasks

Retrying

The API call failed — overloaded, connection dropped — and Claude Code is retrying it.

retrying 3/10 · the error in plain words

Agents

The reply is done, but agents it launched in the background are still working. Claude resumes when they report back.

Which agents, and what each is doing right now

AND FOUR WAYS IT ENDS
DoneClaude’s closing sentence, the files it changed, and one click to see exactly that prompt’s diff.
StoppedWith what to do about it: “sign-in expired — run /login”, “API overloaded — try again”.
Usage limitThe reset time, the status bar keeps it until then, and a second alert when it resets.
InterruptedEnds at once, no notification — you pressed stop, you are right there.
